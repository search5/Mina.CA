CSR 파일 직접 업로드

외부에서 생성한 CSR 파일(.csr 또는 .pem)을 업로드하여 발급 대기 요청으로 등록합니다.

info OpenSSL 수동 CSR 생성 명령어 도움말 
# 1. 2048bit 개인키 생성
openssl genrsa -out domain.key 2048

# 2. SAN(도메인/IP)이 포함된 CSR 생성 (OpenSSL 1.1.1+)
openssl req -new -key domain.key -out domain.csr \
  -subj "/CN=example.com" \
  -addext "subjectAltName = DNS:example.com, DNS:www.example.com, IP:127.0.0.1"
